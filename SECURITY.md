# Security policy

## Supported versions

Only the current `production-smb` image is supported. Rebuilds are published
daily so upstream Nextcloud and Debian fixes can be adopted quickly.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing exploit details, credentials, or personal data.
Include the affected image digest, reproduction steps, and expected impact. You
should receive an acknowledgement within seven days.
